MARUTI PROMOTION UPDATE GUIDE

1. Replace promotion.jpg with a new JPG image using exactly the same filename.
2. Open index.html in Safari to preview.
3. To change the product name and WhatsApp/email message, edit the promotion section inside index.html.
4. Upload changed files to GitHub repository marutidwc-website (main branch).
5. Keep catalog.pdf, hero-art.jpg, maruti-logo.jpeg and product images in the same folder.

The main website design does not need to change.

NOTE: The AeroShell graphic contains stock and specification claims that must be confirmed before publishing.
